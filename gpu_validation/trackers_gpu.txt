JuliaMag feature trackers on GPU — labmac04 (Quadro P1000), Julia 1.11.9, CUDA.jl.

All four trackers now run on the GPU, agreeing with the CPU to machine precision.
Each locates a feature by a device reduction (sum / findmax) over per-cell
quantities built by broadcast — no scalar CuArray indexing. A few scalars come
back to the host: the argmax cell and its 3×3 neighbourhood for the vortex
sub-cell interpolation, and the Nx column averages for the wall zero-crossing.

- vortexcore: exact (argmax + parabolic sub-cell interpolation).
- topologicalcharge: 2.6e-15 (density via the same central-difference edge shift).
- skyrmionpos: ~1e-13 nm, open and periodic-x (circular centroid on the periodic axis).
- domainwallpos: exact (column average reduction + host-side zero crossing).

The whole JuliaMag pipeline now runs on the GPU: fields (exchange/anisotropy/
demag CUFFT/DMI/Zeeman), torques (LLG/Zhang-Li/Slonczewski), solvers (minimizer/
integrator), and the feature trackers.
