The array-programming GPU path issues several broadcast kernels per effective
field (one per term), each with launch overhead, so on this modest GPU it stays
below the lab CPU. Speedup on this hardware would require fused custom kernels
and/or a stronger GPU. Correctness is exact regardless (gpu_check.txt).
