The central-derivative kernels (DMI, Zhang-Li) reuse the exchange field's
Neumann/periodic edge shift, so they reproduce the CPU one-sided boundary exactly
(DMI matches to 0). Slonczewski is a local (derivative-free) broadcast.

DMI + STT + demag + minimizer + integrator all on the GPU together give the same
result as the CPU. (skyrmionpos/topologicalcharge read out on CPU — the feature
trackers are scalar loops, not yet ported.)

=== Performance: DMI + Zhang-Li combined, CPU vs GPU (ms/call) ===
cells      CPU(ms)  GPU(ms)  speedup(CPU/GPU)
16384      0.277    1.179    0.24
65536      1.098    2.209    0.50
262144     4.762    7.601    0.63
1048576    18.959   25.059   0.76

Like the isolated field kernels, the derivative-based DMI/STT (memory-bound, one
broadcast per term, no FFT) do not beat this modest GPU on their own. The speedup
comes when the demag FFT is in the loop (the full effective field reaches ~3x);
in a real current-driven run the demag dominates, so the GPU wins at large meshes.
